Timed Audit Mode

Move selected agents from one Airlock policy group (usually enforcement) into another (usually audit mode) for a set amount of time, then move them back automatically — even if the app was restarted while the timer was running. Uses your Airlock Digital API key and tenant from Settings.

Note: app.py needs to keep running for scheduled reverts to happen automatically. If it's closed while a timer is running, the revert catches up as soon as you start it again — it won't happen while it's off.

VirusTotal

Add your VirusTotal API key to enable uploading compiled .exe files for scanning. Get a free key from your VirusTotal account settings. The key is stored in a local config.json file next to app.py — plaintext, on your machine only.
